# Premium Portfolio Website

A visually stunning, futuristic, and interactive personal portfolio website built with Next.js, React, TypeScript, and modern web technologies.

## Features

- **Premium Design**: Glassmorphism, neumorphism, aurora gradients, and cinematic lighting
- **3D Experience**: Interactive 3D elements, mouse parallax, and depth layers
- **Smooth Animations**: GSAP, Framer Motion, and custom animations throughout
- **Custom Cursor**: Magnetic effect, glow, and cursor trails
- **Loading Screen**: Animated 3D loader with progress indicator
- **Smooth Scroll**: Lenis smooth scroll with scroll progress
- **Command Palette**: Quick navigation with Ctrl+K shortcut
- **Dark/Light Mode**: Theme toggle with smooth transitions
- **Responsive Design**: Perfect on all devices
- **Accessibility**: Keyboard navigation, ARIA labels, and screen reader support

## Tech Stack

- **Framework**: Next.js 14 with App Router
- **Language**: TypeScript
- **Styling**: Tailwind CSS with custom theme
- **Animations**: Framer Motion, GSAP
- **3D Graphics**: Three.js, React Three Fiber, Drei
- **Smooth Scroll**: Lenis
- **Icons**: Lucide React
- **UI Components**: Custom glassmorphism components

## Sections

1. **Hero**: Massive typography, 3D background, floating particles, animated headline
2. **About**: Interactive timeline, animated statistics, skill visualization
3. **Skills**: 3D skill galaxy with floating orbs, interactive tech stack
4. **Projects**: Premium showcases with hover effects, category filtering
5. **Services**: Interactive cards with hover lighting and glass effects
6. **Experience**: Animated timeline with moving indicators
7. **Certificates**: 3D certificate wall with hover zoom
8. **Testimonials**: Infinite carousel with glass cards
9. **Contact**: Premium animated form with floating labels
10. **Footer**: Beautiful minimal design with animated background

## Getting Started

### Installation

```bash
npm install
```

### Development

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### Build

```bash
npm run build
```

### Production

```bash
npm start
```
